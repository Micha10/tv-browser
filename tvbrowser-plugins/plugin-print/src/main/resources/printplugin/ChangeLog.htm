TV-Browser Print Plugin: Release Notes

Version 3.0.2.4 beta

Date: 2019-12-31 (requires TV-Browser 4.x, Java 1.8+)

  • UI: Simplified main dialog (replaced radio by normal buttons, option to start settings)
  • UI: Removed opacity from some controls
  • TODO UI: Integrated the contents of the Extras tab into the Layout tab
  • TODO UI: Added information about paper size, orientation and margins to the Layout tab
  • TODO Settings: Option to select a default print margin (minimum margin of the printer, 10 mm, 20 mm (default), 1 inch)
  • TODO Settings: Option to select a default printer (fallback to the default system printer if not available)
  • TODO Settings: Option to select a default font (fallback to the default UI font "Dialog" if not available)
  • TODO Settings: UI settings for the Print Preview (antialiased text, show margins as crop marks)
  • TODO Settings: UI settings for visual font selection (WYSIWYG)
  • Print Preview: Centered page in preview window
  • Print Preview: Mousewheel support (zoom gestures on selected alternate touch input devices)
  • Print Preview: Exchanged zoom-in and zoom-out button (leading button zooms out, trailing button zooms in)
  • Print Preview: Dark gray background for better contrast
  • Print Preview: Antialias of text (TODO: can be disabled via plugin settings)
  • Print Preview: Page margins are displayed as crop marks if the pointer enters the preview's viewport (can be disabled via plugin settings)
  • Print Preview: Page navigation buttons only visible if page count > 1
  • Code: Upgraded dependencies to TV-Browser 4.x (Core) and TvBrowserCompat 0.5
  • Code: Replaced deprecated API calls
  • TODO: Integrated former program info print dialog into standard settings dialog (as dialog content)
  • Code: Extracted print preview (component)
  • TODO: Schema management (panel) as separate classes
  • Code: Overriden FontChooserPanel to support previewing the font
  • TODO: Integrated JobFactory methods into dedicated print jobs (inherited from AbstractPrintJob)
  • TODO: Added print job compatibility for program info renderer
  • TODO: Added PrinterJob helper class to print via print service, pageable, and DocPrintJob (option to pre-select a printer and get an extended print status)
  • Code: Source level upgrade to Java 1.8 (generics + lamda expressions to reduce boilerplate-code)
  • Code: Clean code and minor fixes
  • Code: PropertyChangeSupport in some components and classes for a later integration of the preview into the print dialog (i. e. live preview of setting changes, WYSIWYG)
